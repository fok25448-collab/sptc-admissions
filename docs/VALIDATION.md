# ผลการตรวจ v1.0.0

## ผ่านการทดสอบในเครื่อง

- Build HTML ครบ 4 หน้า ไม่มี Apps Script template หรือ include ที่ยังไม่ถูกแทนค่า
- JavaScript syntax ผ่านทุกไฟล์ใน API, server, frontend และ scripts
- Unit/API/PostgreSQL tests **7/7 ผ่าน**: ตรวจฟอร์มและไฟล์, ป้องกันแก้ proof, ปฏิเสธ cross-origin, ลำดับเก็บไฟล์ก่อนยืนยันใบสมัคร, retry เลขเดิม, สิทธิ์ฐานข้อมูล, ความจุหลักสูตร และข้อความติดต่อซ้ำ
- Browser tests **5/5 ผ่าน** ใน Chromium: ตรวจ 4 หน้าที่ความกว้าง 390, 820 และ 1440 px, เมนูมือถือ, ไม่มีการล้นแนวนอน, โหลดเพิ่มและตัวกรอง, เลือกหลักสูตรข้ามหน้า, แบบร่าง, กดถัดไปรัว ๆ, แนบไฟล์และส่งใหม่หลัง API ขัดข้อง, ข้อความติดต่อ
- ตรวจรูปแบบ signed-upload request/response เทียบกับซอร์สทางการของ `@supabase/storage-js` 2.116.0

การทดสอบ PostgreSQL ใช้ PGlite และจำลองเฉพาะโครงสร้าง `storage.buckets` ที่ต้องใช้ตอนติดตั้ง ส่วนการทดสอบ HTTP/เบราว์เซอร์ใช้ API fixture เพื่อไม่สร้างข้อมูลจริง จึงไม่ถือว่าเป็นการยืนยันการ Deploy หรือทดสอบ Supabase Storage จริง

## หน้าตาและขอบเขต

ใช้ HTML เนื้อหาหน้าและ CSS จากทั้ง 5 ไฟล์ต้นฉบับ แยกเฉพาะเมนู ส่วนท้าย CSS และ JavaScript เพื่อประกอบเป็นหน้าบน Vercel ข้อความประชาสัมพันธ์เดิมยังอยู่ ส่วนท้ายหน้า “ติดต่อเรา” คงแบบย่อ

แก้เฉพาะข้อบกพร่องการโต้ตอบ เช่น พื้นที่แตะเมนู ปุ่มระหว่างส่งข้อมูล การเลือก radio การแสดง error โหลดภาพสำรองซ้ำไม่สิ้นสุด CSS comment ผิดรูปแบบในหน้าติดต่อ และการใช้ฟอนต์ Kanit ที่ต้นฉบับโหลดไว้แต่ยังไม่ได้กำหนดให้บางหน้า

ไฟล์ `js_global.html` และ `.gs` ไม่ได้แนบมา การโหลดการ์ดหลักสูตรหน้าแรกและ backend จึงเป็นส่วนที่เขียนทดแทน ไม่สามารถอ้างว่าเทียบภาพกับระบบเดิมครบทุกส่วนแบบพิกเซลต่อพิกเซล

## ต้องตรวจบนระบบจริงหลังตั้งค่า

1. Vercel Environment Variables และ URL ต้นทางที่อนุญาต
2. Supabase service-role JWT, ตาราง ฟังก์ชัน และ private Storage bucket
3. อัปโหลดไฟล์จริงและตรวจเลขใบสมัคร/แถวข้อมูล/ไฟล์ final
4. หลักสูตร จำนวนรับ ปีการศึกษา ข้อความประกาศ ช่องทางติดต่อ และเอกสารนโยบายจริง
5. ภาพภายนอกและ Google Maps ที่ต้นฉบับอ้างอิง

ชุดไฟล์นี้ไม่มีคีย์ของเจ้าของระบบ ไม่ได้สร้าง GitHub repository หรือ Deploy ไปยังบัญชี Vercel/Supabase ของเจ้าของระบบจากสภาพแวดล้อมนี้

## อัปเดตแอนิเมชัน 13 กันยายน 2569

เพิ่ม motion.css และ motion.js เป็นส่วนกลาง และโหลดผ่าน build ของทั้ง 4 หน้า ตรวจ build และ JavaScript syntax หลังปรับแล้ว ผลทดสอบ 7/7 และ 5/5 ด้านบนเป็นผลของรุ่นก่อนเพิ่มแอนิเมชัน ไม่ได้รันทดสอบฐานข้อมูลซ้ำในงานปรับภาพครั้งนี้ แอนิเมชันใช้ progressive enhancement เนื้อหาไม่ถูกซ่อนถ้า JavaScript ไม่ทำงาน รองรับ reduced motion และไม่ดักหรือยกเลิก event ของฟอร์ม
